# Marketing Analytics — Customer Segmentation

## 📌 Overview

This project was completed as part of the Marketing Analytics course at the University of Milano-Bicocca.

The project focuses on customer analytics and segmentation using transactional data. It covers data preparation, exploratory data analysis, RFM analysis, Customer Lifetime Value (CLV), predictive CLV, and customer segmentation.

## 🎯 Objectives

The main objectives of this project are to:

- Prepare and clean customer transaction data
- Perform exploratory data analysis (EDA)
- Calculate RFM (Recency, Frequency, Monetary) metrics
- Estimate Customer Lifetime Value (CLV)
- Develop a predictive CLV model
- Segment customers based on their characteristics and purchasing behavior
- Generate visualizations to support marketing insights
